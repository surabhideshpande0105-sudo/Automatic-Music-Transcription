200ms chunks are the heartbeat

Sound is numbers: sample rate × time. At 22050 Hz, 200ms = 4410 samples. amt_audio.py:9 read_wav_mono() forces mono + that rate; FileChunker slices file audio, MicStream yields live mic blocks of the same size.

Your my_first_audio.wav is 2s → 10 chunks. test_latency.py measured ~0.15ms per chunk for I/O + gate — budget passes before the model runs.

Mic = same chunks, different source: sounddevice.InputStream(blocksize=chunk) calls back every 200ms into a queue. File and mic converge to one process(chunk) interface.
from amt_audio import FileChunker
for c in FileChunker("my_first_audio.wav", chunk_ms=200):
    print(len(c))  # 4410 ...
