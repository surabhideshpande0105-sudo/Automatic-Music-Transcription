The app is thin by design

app.py does no ML. It collects bytes, calls one function, and shows downloads. Two tabs share one variable: audio_bytes.

Score viewing leaves the app: save MusicXML, open generated/view_notation.html → Choose File (OSMD renders, no MuseScore).

Run: streamlit run app.py → open http://localhost:8501 in Edge/Chrome. Keep the terminal alive; Ctrl+C stops it.
