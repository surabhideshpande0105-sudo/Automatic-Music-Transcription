One instrument, six ranges

The app is no longer piano-only. An instrument dropdown in app.py selects a preset from INSTRUMENT_PRESETS (amt_offline.py:5) — each a frequency window plus a MIDI range that prunes impossible guesses (guitar can't play C1).

Basic Pitch is instrument-agnostic but best one instrument at a time — the presets encode that honesty. Full band mixes need stem separation first (roadmap: Demucs + per-stem transcription).

Fallback safety: app.py:13 re-defines the presets if the import ever fails, so users see music options, not an ImportError.
