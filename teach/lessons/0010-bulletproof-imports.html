Never show a traceback

Your ImportError: INSTRUMENT_PRESETS happened with the name present in the file — mixed 3.12/3.13 __pycache__ served a stale module to Streamlit's reloader. Two rules came out of it.

Rule 1 — imports live at the top, with a fallback. app.py:13 tries the import and re-defines the presets on failure. Mid-file imports re-run on every Streamlit rerun and hide dependency problems.
Rule 2 — stale bytecode is a suspect. Any impossible ImportError: stop the app, delete __pycache__, rerun.
from amt_offline import transcribe_file_auto
try:
    from amt_offline import INSTRUMENT_PRESETS
except ImportError:
    INSTRUMENT_PRESETS = {...}  # same presets, app keeps working
