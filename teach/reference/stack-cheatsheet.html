Stack cheatsheet

What each library does in this project. Print me.

numpy / scipy — arrays + STFT math. Used in amt_audio.py, amt_offline.py.
librosa 0.10.2 — load(), stft(), piptrack(). Placeholder monophonic pitch. docs
soundfile / sounddevice — decode audio; mic callback blocks. MicStream yields 200ms float32.
pretty_midi — reads MIDIs for the piano-roll plot in app.py:37. repo
music21 — converter.parse(mid).write("musicxml") in amt_score.py:49. docs
matplotlib (Agg) — server-side piano-roll PNGs; no GUI needed.
streamlit — file_uploader, audio_input, pyplot, download_button. docs
basic-pitch (Spotify, ICASSP 2022) — lightweight polyphonic CNN, ONNX default on Windows. repo / paper
OpenSheetMusicDisplay — renders MusicXML in generated/view_notation.html. site
