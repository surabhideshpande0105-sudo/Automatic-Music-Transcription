Pipeline cheatsheet

File paths = data contracts.

MIDI holds performance (pitch 21–108, start/end, velocity). MusicXML adds engraving (bars, clef, noteheads). Confusing them breaks the viewer.
Latency split: MIDI events ~200–500ms can stream; score needs 1–2s lookahead for beat/key. See test_latency.py (I/O) vs model cost.
